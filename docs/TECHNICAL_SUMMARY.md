# 다시가게 기술 요약

## 전체 시스템 구조

Next.js 16 App Router의 서버 렌더링 화면과 React 클라이언트 컴포넌트를 사용한다. 공통 레이아웃 안의 `DemoProvider`가 브라우저에서 `DemoRepository`를 통해 `restore-demo-v1` localStorage를 읽고 공유한다. 서버 렌더와 최초 클라이언트 렌더는 로딩 상태로 맞춘 뒤 브라우저에서 데이터를 불러온다. Node.js 서버 Route Handler는 선택적 개발용 AI 사진 분석에만 사용하며 일반 시연에는 서버 DB나 API 키가 필요 없다.

## 주요 구성과 데이터 흐름

- `components/asset-registration.tsx`: 사진 선택·압축, 입력 검증, 최종 확인 및 로컬 등록.
- `components/demo-assets.tsx`, `asset-detail.tsx`: 자산 검색·필터·상세·관심 표시.
- `components/smart-matching.tsx`, `lib/matching/match.ts`: 수요 저장과 규칙 기반 추천.
- `components/transaction-simulation.tsx`, `lib/repositories/demo-repository.ts`: 확인 후 가상 거래 및 자산 완료 상태를 하나의 저장 객체에 기록.
- `components/impact-dashboard.tsx`, `lib/simulation/impact.ts`: 완료 사례 집계와 별도 가정 시뮬레이터.
- `components/demo-guide-bar.tsx`: 접을 수 있는 시연 순서·빠른 이동·확인 후 초기화.
- `app/api/assets/analyze/route.ts`, `lib/ai/`: 서버 측 선택형 사진 분석. 기본 비활성화이며 프로덕션·Vercel에서는 차단된다.

사진은 브라우저에서 크기를 제한·압축해 localStorage에 저장한다. 서버 사진 분석은 사용자가 요청할 때만 사진을 외부 API로 전송하며 분석용 서버 파일을 남기지 않는다. 서버 키는 클라이언트에 전달하지 않는다.

## 매칭 알고리즘

등록 가능 상태가 아니거나 기한이 지난 자산, 카테고리 불일치, 예산 초과, 인수 희망일이 처분 예정일보다 늦은 자산은 제외한다. 일치 카테고리 40점, 가격 비율 15/20/25점, 지역 8/18/25점, 일정 5/7/10점을 합산한다. 세부 지역 미입력 시 같은 시·군은 지역 만점이다. 점수 내림차순, 동점은 등록일 최신순과 ID순이며 점수는 거래 성공 확률이 아니다.

## 정책 효과 계산

완료된 가상 거래에 대해서만 자산과 거래 ID의 중복을 제거해 집계한다. 등록 자산 수는 완료 여부와 관계없이 브라우저의 자산 전체다.

- 가상 거래 총액 및 판매자 자산 회수액: 완료 거래금액 합계. 두 값은 동일한 차감 전 금액이며 합산하지 않는다.
- 판매자 순회수액: `거래금액 - 판매자 부담 비용`의 합계.
- 구매자 추정 차액: `비교 신품 가격 - 거래금액 - 구매자 운송비`. 기준가 누락은 추정 불가, 음수는 추가 지출 가능으로 표시한다. 설치·수리비는 제외한다.
- 장비 재사용 건수: 가상 완료 자산 수이며 실제 재사용 실적이 아니다.
- 가정 시뮬레이터: `참여 점포 수 × 점포당 완료 건수`와 건당 평균을 곱한다. 저장된 거래 집계와 합산하지 않는다.

등록→매칭→완료 흐름의 매칭 단계는 저장된 수요 조건 수이며 매칭 성사 수나 전환율이 아니다. 실제 정책 KPI는 추후 실증 단계에서 측정해야 한다.

## 시연 데이터와 실제 데이터

초기 사례와 사용자 입력은 가상 시연 정보다. localStorage는 브라우저·기기별로 독립적이고 삭제·변조될 수 있으며 탭 간 동시 쓰기 경쟁을 완전히 막지 못한다. 가상 기록은 실제 매매, 검증된 시세, 기관 협약 또는 정책 효과가 아니다.

## 실서비스 확장 전제

기관과 역할·제도 적합성을 확인하고, 인증·권한, 개인정보 보호, 소유권·허위 자산 검증, 거래 안전·분쟁 처리, 서버 DB·이미지 저장·트랜잭션 및 측정 동의·비교 기준을 설계해야 한다. AI 공개 운영에는 인증, 신뢰할 수 있는 분산 요청 제한, 비용 관리와 외부 전송에 대한 보호 절차가 필요하다.
