# 다시가게 발표 시연 가이드

## 시작 전 확인

- 사용할 **같은 브라우저**에서 서비스를 열고, 상단 **공모전 시연 안내 → 시연 데이터 초기화**를 선택해 확인한다. 초기화하면 기존 사용자 등록·관심 표시·수요·가상 거래가 모두 삭제된다.
- 가상 시드 8건과 가상 완료 거래 0건을 확인한다. 브라우저가 저장소를 차단하지 않았는지와 화면 확대·네트워크를 점검한다.
- 가상 시드 날짜는 초기화한 날부터 상대 날짜로 생성된다. 이전 저장 자산이 만료됐다면 초기화 후 다시 진행한다. 초기화는 사용자 등록·관심 표시·수요·가상 거래를 모두 삭제한다.
- 사진은 시연용 이미지 또는 사진 없이 진행한다. AI는 선택 기능이며 프로덕션에서는 차단되므로 발표의 필수 단계에 넣지 않는다. 모든 수치·가격·인물·거래가 가상임을 설명한다.

## 60~90초 시연 순서

| 시간 | 화면과 조작 | 발표 핵심 및 예상 결과 |
| --- | --- | --- |
| 0~10초 | `/`에서 공모전 시연 안내를 열고 **폐업자: 장비 등록** 선택 | 폐업 자산의 회수와 창업 설비 부담 완화를 연결하는 정책 제안임을 소개한다. |
| 10~30초 | 사진 건너뛰기 → 카테고리 `주방·카페`, 세부 품목 `커피머신`과 아래 가상 장비 입력 → 확인 후 등록 | 실제 거래 없이 이 브라우저에 사용자 등록 데모가 저장된다. |
| 30~50초 | 시연 안내에서 **창업 조건과 추천** 선택 → 카테고리 `주방·카페`, 세부 품목 `커피머신`과 아래 조건 입력 | 등록한 장비가 규칙 기반 추천에 표시된다. 같은 카테고리라도 다른 세부 품목은 추천되지 않는다. 점수는 성공 확률이 아니다. |
| 50~65초 | 해당 장비 상세 → **거래 시뮬레이션 시작** → 아래 가상 금액 입력·확인 | 실제 결제 없이 장비 상태와 가상 거래 기록이 함께 변경된다. |
| 65~85초 | **가상 정책 효과 확인** → 거래금액, 순회수액, 구매자 추정 차액 확인 | 시연 데이터 계산값과 실제 정책 성과를 구분하고 산식을 설명한다. |

## 발표용 입력값과 예상 결과

아래 값은 모두 임의의 **가상 시연 값**이며 실제 가격이나 효과가 아니다. 날짜는 발표 당일의 브라우저 현지 날짜 기준으로 선택한다.

- 자산: `발표 시연 커피머신`, 카테고리 `주방·카페`, 세부 품목 `커피머신`, 상태 `일반 중고`, 희망 가격 `500000`원, `수원시`, 세부 지역 공란, 처분 예정일 **오늘부터 30일 후**.
- 창업 조건: 카테고리 `주방·카페`, 세부 품목 `커피머신`, 최대 예산 `1000000`원, `수원시`, 세부 지역 공란, 인수 희망일 **오늘부터 5일 후**.
- 예상: **세부 품목 정확 일치 40점**, 예산 25점, 시·군 25점, 일정 10점으로 등록 자산 **100점**. 다른 시연 자산도 추천될 수 있으므로 제목으로 찾는다.
- 가상 거래: 거래금액 `500000`원, 판매자 부담 비용 `10000`원, 구매자 운송비 `20000`원, 비교용 신품 가격 `800000`원, 근거 `임의 시연 기준가`.
- 초기화 후 위 거래만 완료했다면: 등록 자산 9건, 가상 완료 1건, 거래 총액·판매자 회수액 각 500,000원, 판매자 순회수액 490,000원, 구매자 추정 차액 280,000원. 설치·수리비는 제외한다. 실제 실적이 아니다.

## 실패 시 대체 방법

- 저장 오류: 브라우저의 저장 공간·사이트 저장 권한을 확인한다. 초기화는 기존 데이터를 지우므로 발표 전에만 확인 후 실행한다.
- 추천 없음: 처분 예정일이 인수일보다 뒤인지, 자산 상태가 거래 가능인지, 예산·카테고리·세부 품목이 맞는지 확인한다. 저장된 오래된 시드 자산의 날짜가 지났다면 시연 데이터 초기화로 새 상대 날짜를 만들거나 미래 처분일로 새 가상 장비를 등록한다.
- 사진·AI 오류: 사진 없이 수동 등록한다. AI 결과를 실제 분석 결과처럼 꾸미지 않는다.
- 네트워크 또는 기기 문제: 발표 전에 직접 촬영한 최신 화면 캡처 또는 녹화본으로 전환하고, 녹화 시연임을 명시한다.

## PPT에 활용할 화면

1. 메인: 서비스의 문제와 연결 구조.
2. 자산 등록 최종 확인: 폐업자 관점과 시연 데이터 안내.
3. 스마트 매칭 결과: 점수 산식과 추천 이유.
4. 장비 상세의 가상 거래 확인: 실제 결제 없음 안내.
5. 정책 효과 대시보드: 가상 집계와 별도 가정 계산기.
6. 정책 소개: 가정된 대상·지역·운영 단계, 미확정 비용 산식, 기관 역할 제안과 실증 지표.

화면 캡처에는 가상 데이터 안내가 보이도록 하고 개인정보나 실제 자산 정보를 포함하지 않는다.
