# 다시가게(RE:STORE) 제품 명세

## 목적과 정책 가설
폐업 예정 소상공인이 집기·설비·장비의 회수 기회를 찾고, 예비 창업자와 다른 소상공인이 필요한 자산을 찾도록 연결하는 공모전용 프로토타입이다. 지역 자원순환, 폐업·재창업 지원 연계 및 정책 효과 측정 가능성을 시연한다. 자산 회수와 비용 절감은 검증할 정책 가설이며 이 프로토타입 자체가 효과를 입증하지 않는다.

## 사용자
- **폐업 예정 소상공인:** 자산, 사진, 희망 가격, 지역과 철거 예정일을 입력하고 거래 완료 시뮬레이션을 체험한다.
- **예비 창업자 및 소상공인:** 지역·업종·예산으로 장비를 찾고 조건에 따른 규칙 기반 추천과 구매비 절감 추정치를 확인한다.
- **정책 담당자 및 심사위원:** 서비스 흐름, 가상 지표, 제안된 기관 역할과 시범사업 운영 방안을 확인한다.

## 범위와 화면
| 화면 | 주요 기능 및 상태 |
| --- | --- |
| 메인 `/` | 정책 목적과 시연 안내, 등록·검색·매칭·대시보드·정책 소개 이동 |
| 자산 등록 `/sell/new` | 선택적 사진과 장비 정보를 3단계로 입력·확인하고 이 브라우저에 저장. 성공·입력 오류·저장 실패 표시 |
| 장비 검색 `/market` | 가상·사용자 데모 자산 검색, 필터·정렬, 관심 표시 및 브라우저 데이터 초기화 |
| 장비 상세 `/market/[id]` | 사진·조건·상태, 관심 표시 및 확인을 거친 가상 거래 완료 시뮬레이션 |
| 스마트 매칭 `/match` | 카테고리, 예산, 지역, 인수 희망일을 저장하고 규칙 기반 점수와 일치 사유를 표시. 결과 없음과 입력 오류 처리 |
| 정책 효과 `/impact` | 현재 브라우저의 가상 시뮬레이션 지표와 가정·산식·한계 표시. 완료가 없거나 추정 불가한 경우 별도 표시 |
| 정책 소개 `/policy` | 문제, 제안된 기관별 역할, 정책 연계 구상, 시범사업 및 실서비스 전제 설명 |

모든 화면에 시연 환경임을 알리고 지표·추천·거래 버튼 주변에도 해당 한계를 표시한다. 로딩, 저장 실패, 빈 목록, 없는 자산을 처리하고 모바일과 키보드 사용을 지원한다. 회원가입과 연락처 수집 없이 체험한다.

## 사용자 흐름
1. 폐업 예정자: 메인 → 등록 → 검증 및 로컬 저장 → 상세 → 거래 완료 시뮬레이션 → 대시보드에서 반영 확인.
2. 창업자: 검색과 필터 또는 조건 입력 → 추천 점수와 이유 확인 → 상세 → 거래 완료 시뮬레이션 → 가정에 따른 절감 추정 확인.
3. 심사위원: 메인 → 정책 소개와 시범사업 구상 → 대시보드의 가상 지표 및 산식 확인.

## 추천과 효과 표시 원칙
- 추천은 카테고리·가격·지역·일정 기준으로 산출한 규칙 기반 점수로, 조건별 배점과 불일치 이유를 함께 보여준다. 점수는 거래 성공 확률이 아니며 AI 분석이 아니다.
- 비교 기준가가 있는 자산만 `가상 신품 비교 기준가 - 시뮬레이션 가격 - 구매자 운송비`을 **예상 구매비 절감액**으로 표시한다. 구매자 운송비를 반영하고 설치·수리비는 제외한 단순 추정이며 실제 가격이나 절감액을 보장하지 않는다. 기준가가 없으면 추정 불가로 표시한다.
- 완료 건수는 이 브라우저에 기록된 **가상 거래 완료 시뮬레이션 건수**, 회수액은 해당 건의 시뮬레이션 가격 합계, 절감액은 추정 가능한 건의 추정치 합계다. 각각 실제 실적이 아니다. 기준가가 없는 건수와 집계 범위를 함께 표시하고 중복 완료를 막는다.
- 브라우저 데이터는 다른 사용자·기기와 공유되지 않고 삭제 또는 변경될 수 있으므로 정책 성과 통계로 사용하지 않는다. 시드 데이터와 사용자 입력 역시 시연 데이터로 표시한다.

## 정책 소개 및 시범사업 제안
지자체는 지역 모집·홍보, 지원기관은 폐업·재창업 상담과 관련 지원제도 안내, 운영 주체는 자산 등록·연결 및 시범사업 운영, 참여자는 자산·수요 정보를 제공하는 역할을 **제안**한다. 실제 협약이나 기관 참여는 확인되지 않았다. 소규모 지역에서 모집 → 자산 등록 및 수요 연결 → 참여자 동의하에 결과 확인 → 기준선과 비용을 포함한 평가 순으로 시범사업을 검토한다. 실제 정책 연계 여부와 대상·조건은 운영 전 해당 기관의 최신 공식 자료로 확인한다.

## 제외 및 확장 전제
실제 결제·실시간 채팅·실제 매매계약·본인 인증·복잡한 회원가입·자동 대출/보증 심사는 구현하지 않는다. 실서비스 확장 전 인증과 접근통제, 개인정보 수집 최소화·보호, 자산 소유권 확인, 허위 매물 대응, 거래 안전장치 및 분쟁 처리, 기관 협의와 유효한 성과 측정 체계가 필요하다.

## 선택형 사진 분석
사진 선택 후 이용자가 분석을 요청하면 사진이 서버를 통해 외부 AI 서비스로 전송된다. 제안은 확인·수정 후 명시적으로 적용하며, 정확한 모델·연도·가격·상태·사용기간·소유권은 확인 대상으로 남긴다. 키나 모델이 없거나 분석이 실패해도 수동 입력을 사용할 수 있다. 공개 배포 환경에서는 인증 및 분산 요청 제한이 준비되기 전까지 기능이 서버에서 차단된다.
